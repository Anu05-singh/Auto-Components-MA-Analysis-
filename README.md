# M&A Target Screening – Auto Components Business

## Project Overview
This project focuses on identifying five potential strategic acquirers for an auto-components business.

## Target Company Financial Snapshot

- Revenue: ₹500 Crore
- EBITDA: ₹75 Crore
- EBITDA Margin: 15%

## Project Objectives
- Identify five potential strategic buyers.
- Evaluate strategic acquisition rationale.
- Assess financial affordability.
- Examine previous acquisition experience.
- Understand potential business synergies.

## Skills Demonstrated
- Mergers & Acquisitions (M&A)
- Financial Analysis
- Strategic Buyer Screening
- Enterprise Valuation
- Corporate Finance
- Financial Research

## Project Type
Independent Financial Research Project.

## Disclaimer
This is an educational project based on illustrative target-company financial information. It does not represent an actual acquisition recommendation.
